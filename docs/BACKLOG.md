# Нужно решение

| Что | Почему отложено | Состояние |
|---|---|---|
| Чистка старых картинок | `data/generations` растёт, лимита нет | нужно решение: лимит по количеству или по дате |
| Второй человек у админки | сейчас один логин и пароль | нужно решение: заводить ли таблицу пользователей |
| Экспорт и импорт страницы | перенос формы между экземплярами | нужно решение: файл или API |
| Публичный доступ без VPN | сейчас подразумевается сеть или туннель | нужно решение: TLS-прокси и правила, если выставлять наружу |
