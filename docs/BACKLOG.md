# Отложенное

## Нужно решение

| Что | Почему отложено | Состояние |
|---|---|---|
| Алиасы переименованных элементов | переименование `id` ломает обвязку в n8n | решение: алиасы в форме, старое имя остаётся рабочим |
| Черновик и публикация | пока одна версия формы, правка сразу видна | решение: две версии в `data/forms`, публикация копией |
| Вход в админку | сейчас админки нет; ограничение — сеть и VPN | решение: basic auth в nginx на `/admin` |
| Ротация журнала в файл | журнал только в памяти, 200 записей | нужно решение: файл с ротацией или оставить в памяти |
| Чистка старых картинок | `data/generations` растёт | нужно решение: лимит по количеству или по дате |

## Решение есть, ждёт этапа B2

| Что | Решение |
|---|---|
| Повтор отмены (redo) | второй стек на 20 шагов |
| Удаление страницы | `DELETE /api/v1/admin/forms/<slug>?confirm=<slug>`, последнюю страницу удалять нельзя |
| Создание страницы из админки | кнопка «Новая страница»: slug, заголовок, пустой канвас |
| Алиасы имён | `aliases` в форме: старое имя метода остаётся рабочим после переименования `id` |
| Мультивыделение и выравнивание | Shift+клик, выравнивание по краям и центрам |
| Масштаб канваса | zoom 50–150 %, только отображение, координаты не меняются |
| Копирование элемента | Ctrl+D, новый `id` с суффиксом `_copy` |
| Несколько страниц | список слева в админке, `/p/<slug>` |
| Адаптивность | канвас масштабируется целиком; мобильная раскладка не планируется |

## Не делаем

| Что | Почему |
|---|---|
| Своя бизнес-логика, вычисления, интеграции | это n8n |
| Произвольный JS/HTML в элементах | XSS и непредсказуемая вёрстка |
| Загрузка файлов пользователем | картинки кладёт бэкенд |
| Многопользовательские права | админ один |
| Внешние CDN и шрифты | работа без интернета |
