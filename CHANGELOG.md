# Журнал изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
версии — [SemVer](https://semver.org/lang/ru/).

## [Unreleased]

### Изменено

- портал больше не описывается как конструктор «для n8n»: бэкенд — любой процесс
  с HTTP (FastAPI, Go, PHP, Make, свой скрипт); n8n остался примером;
- `docs/N8N.md` переименован в `docs/BACKEND.md`: сначала общий контракт,
  потом пример на n8n;
- формулировки в README, VISION, ARCHITECTURE, OPERATIONS, SECURITY, DECISIONS
  и в интерфейсе админки — про бэкенд, а не про конкретный инструмент.

### Добавлено

- вход в админку — по форме и подписанной куке вместо диалога HTTP Basic;
- API-токены: создаются и отзываются в админке, в файле только хеши; страницы
  админки пускают лишь по сессии, токен — только для API;
- цели событий: элемент хранит имя цели, адреса — отдельно (`data/targets.yaml`),
  манифест отдаёт имена, но не адреса; управление в админке — «Цели событий»;
- элемент «Открытие» (`onload`): невидимый триггер, шлёт `on_open_<id>` при загрузке
  страницы — для дашбордов, которые сразу спрашивают статусы;
- состояние страницы без привязки к сессии (`POST /api/v1/forms/<slug>/state`) и
  статусы страниц в списке, обновляются опросом;
- страница по умолчанию: корень `/` ведёт на неё, список страниц — на `/pages`;
- на странице панель «К списку страниц», в предпросмотре ещё «В админку»; снизу
- магнит работает и при изменении размера, включается отдельной галочкой;
- у элементов появились минимальные размеры: подпись плюс сам контрол;
- в «Настройках» страницы можно задать высоту, удаление страницы переехало туда же;
- поля в модальных окнах получили явные фон и цвет — текст снова читается.

## [0.2.0] — 2026-11-22

### Добавлено

- удаление страницы из админки: подтверждение, последнюю страницу удалить нельзя;
  вместе со страницей уходят файлы формы и значения всех её сессий;
- вход в админку: HTTP Basic, логин и пароль из `ADMIN_USER` / `ADMIN_PASSWORD`;
  без пароля админка отвечает 503, а не открывается всем;
- предпросмотр черновика `/p/<slug>?draft=1` — тоже только для админа;
- элемент «Список» (`list`) для строк от бэкенда;
- алиасы: переименование элемента не рвёт обвязку в n8n;
- журнал вызовов в `logs/calls.jsonl` с ротацией по 2 МБ;
- чистка снимков сессий старше 30 дней при старте.

### Изменено

- правки дизайнера уходят в черновик, живая страница меняется только публикацией;
- README сокращён, подробности — в `docs/`.

### Инфраструктура

- LICENSE (MIT), CI на GitHub Actions, `.editorconfig`, `.gitattributes`,
  `.dockerignore`, `SECURITY.md`, `CONTRIBUTING.md`, `docs/OPERATIONS.md`.

## [0.1.0] — 2026-11-21

### Добавлено

- контракт методов: `<slug>.<id>`, `<slug>.post_<id>`, `<slug>.<event>_<id>`;
- 9 видов элементов, канвас фиксированной ширины, рендер на сервере;
- состояние по сессиям, живые обновления через SSE;
- хранилище картинок и галерея;
- демо-драйвер вместо n8n: событие → статус → картинка;
- дизайнер: палитра, канвас, инспектор, перетаскивание, отмена;
- Docker, пример nginx, VISION, ARCHITECTURE, DECISIONS, BACKLOG.
